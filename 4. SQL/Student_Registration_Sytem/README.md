# 🎓 Student Registration System

A desktop application built with **Python**, **Tkinter**, and **MySQL** that allows educational institutions or administrators to manage student records efficiently. The system provides a user-friendly graphical interface (GUI) to handle full CRUD (Create, Read, Update, Delete) operations on student data.

---

## ✨ Features

- **Add Student Records:** Register new students with details like Student ID, Name, Email, Gender, Contact Number, DOB, and Address.
- **View & Display:** Browse all registered students in an interactive data table (`Treeview`).
- **Update Information:** Select any student from the table to auto-fill their details for easy editing and updating.
- **Delete Records:** Safely remove student entries with confirmation prompts.


---

## 🛠️ Tech Stack

- **GUI Framework:** Python Tkinter (with `ttk` modules)
- **Database:** MySQL
- **Database Connector:** `mysql-connector-python` (or `PyMySQL`)
